# Read-Able
ReadAble is an accessibility-focused web application designed to provide a personalized and comfortable reading experience. It helps users reduce visual and cognitive load through adjustable text size, spacing, contrast, focus mode, sentence highlighting, and reading assistance. The project follows a user-centered, iterative development approach.

## Key Features

- **Personalized Reader**: Dual-mode reading interface with extracted distraction-free text or canvas PDF view.
- **Settings & Accessibility**:
  - Live typography customization (OpenDyslexic, Lexend, Inter, System fonts)
  - Contrast themes (Standard, High Contrast, Cream background)
  - Text scaling and line spacing adjustments
  - Dyslexia-friendly font, high contrast, and reduced motion accessibility modes
  - Text-to-speech Read Aloud with custom voice selection, pitch, rate controls, and auto-read on open
  - Daily reading goals tracking with midnight auto-reset
  - Profile and security controls: name/phone update, password change, data export, and reading history cleanup
- **AI Reading Assistant**: Groq-powered technical and simple level explanations, summaries, and definitions.
